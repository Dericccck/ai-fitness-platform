# Memory 实施与验收记录

本文记录本次实现和仍未完成的生产验收事项。总体结论：可以在隔离环境继续测试，当前不能认定为生产最终版。

## 当前实现

- 用户消息在签名身份对应单机构时加密保存为提取来源；流式对话完成、历史提交和提取任务创建使用同一数据库事务。非流式入口另行提交任务，对话仍可在任务创建失败时完成。
- 后台 Worker 根据受控的类型和槽位提取候选，核对原文证据；针对相关旧记忆进行规则及模型辅助比较，不确定时请求澄清。候选和通知任务原子保存，候选由用户明确批准或拒绝。
- 正式记忆支持多条受控槽位记录，批准时进行目标版本、相关记录快照、幂等和遗忘边界校验，记忆写入和候选状态在同一事务中提交。旧的对话式记忆写工具仍采用兼容的写入路径。
- 训练计划按权限读取训练相关记忆，并校验模型声明关联的记忆 ID 和版本；声明不等于已经验证的实际使用。普通对话默认仅注入有效的沟通偏好，运行时注入的内容不写入 Checkpoint。记忆设置按用户和机构隔离。
- 来源到期清理、候选和正式记忆过期治理由 Worker 执行。用户撤销/纠正或变更设置时更新版本、使旧来源和候选失效并删除旧摘要；在途旧摘要通过主体版本栅栏阻止重新发布。下一轮对话不把旧版本 Checkpoint 的历史送给模型，会话提交标记和确认单不因此删除。
- PostgreSQL 保存正式记忆和版本；本次未引入外部 Memory 框架或向量库。来源和候选使用应用层加密。

## 评测范围

`fitness-agent-service/evals/memory_labeled.json` 是人工构造的 54 条提取和 32 条新旧关系样本，逐例输出见 `fitness-agent-service/evals/memory_evaluation_20261029.json`。提取仅核对类型集合，不验证完整的值、证据和安全性；关系评测一条撤销场景未支持；合成样本和单次模型结果不能代替真实流量验收。

单次真实模型评测中，提取 51/54 条类别集合匹配；关系判断 28/31 条可评分项匹配，另有 1 条撤销未支持。误提场景包括假设和对他人的描述，关系误差以需要澄清为主。Agent 完整测试为 957 项通过、41 项按环境跳过；前端构建通过、现有 27 项测试通过。前端现有测试不等同于 Memory 页面端到端验收。

隔离 PostgreSQL 测试覆盖迁移、来源去重与 epoch、候选事务回滚与并发审批、Worker 租约、从来源到审批的端到端流程，以及摘要屏障；13 项通过。端到端测试使用合成模型响应，真实模型评测并未验证数据库事务。

## 上线前仍需完成

1. 正式记忆正文当前保存在 PostgreSQL JSONB，尚未实现方案中的应用层加密、加密密钥轮换和受控 HMAC 身份；数据库备份和访问控制不能替代这一工作。
2. 已发出的模型请求无法撤回。确认流程恢复和流式响应仍需完整的记忆版本检查、取消及冲突处理；跨服务和正在生成的输出不能宣称立即遗忘。当前的会话提交标记并不是完整聊天消息表；Checkpoint 内历史及完整聊天记录需要单独的保留、删除和访问策略。
3. 提取模型在假设、他人表述等合成样本上仍出现误提取；完整的条件、重复表达、时间重叠、显式撤销和来源顺序处理尚未覆盖。须增加有授权的真实样本和独立标注，按值、证据、操作、漏提和误提分别验收。
4. 记忆引用/实际使用事件、幂等计数、最近使用时间和基于复核的遗忘策略尚未实现。仅注入 Prompt 不能代表模型确实使用了记忆。
5. 旧记忆工具保存路径尚未完全统一到受控槽位及新候选协议；多机构时来源采集不会猜测机构，需明确机构选择和完整回退体验。长时间任务、补偿、监控告警、限流、灰度、备份恢复及故障演练仍需生产环境验证。
6. 结构化范围、训练/普通对话的相关性选择、时间规则、令牌预算和引用可追溯性需要继续完善。可选向量召回与框架集成不属于本次已实现能力。

异步提取的程序默认值及生产环境示例均为关闭；开发环境示例为开启。常规聊天入口不会回退到旧同步提取。该开关不关闭记忆管理接口和用户显式发起的工具操作；在完成上线前事项后需由部署方明确开启。
